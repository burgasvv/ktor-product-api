
# ___Product Store API___

## Версии
+ Ktor 3.3.1
+ OpenJDK 11
+ Maven 3.9.9

## Основной стек зависимостей
+ Exposed DB
+ Postgresql
+ Authentication Basic
+ Routing
+ Serialization

## Описание
    API для организации работы с продуктовым магазином

## Запуск приложения
* > Запустить приложение в среде разработки, compose.yaml или jar файл
* > Протестировать запросы в файле request-test.http
